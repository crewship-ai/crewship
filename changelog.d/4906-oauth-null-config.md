- **Starting or completing an OAuth flow for a credential that is not set up for OAuth now returns 400 instead of 500 (#4906).** A credential that was never created as OAuth (for example an API key) has no OAuth columns at all. Loading them failed, so `POST /api/v1/oauth/initiate` answered `500 Failed to load credential`. Initiate, exchange and loopback now all answer `400 Credential missing OAuth configuration`, the same answer as for an OAuth credential with an empty configuration. Exchange gives that 400 before calling the provider, instead of a 502 from an empty token URL.
