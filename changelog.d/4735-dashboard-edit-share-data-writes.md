- **People you share a Dashboard with for editing can now change its data, not only its code (#4732).** Dashboard data writes (`POST /api/v1/pages/{slug}/artifact/data/{collection}`, `crewship page artifact data batch`, and the Dashboard page itself) were limited to the owner and the owner's agent run, so an Edit share could publish new source but got 403 on every data save. Data writes now use exactly the predicate that source saves use: an explicit Page write grant or an inherited folder write. They are pinned to the latest code version, take the same storage and free-disk admission, and are recorded with the editor as the author. Read and Comment shares, workspace roles without a grant (including ADMIN), the private-audience seal, revoked grants and agent runs acting for anyone but the owner are still refused, with nothing written; what readers can read is unchanged.
