- **One place answers whether an agent may change a Sheet you attach in chat, and why not.** `GET /api/v1/pages/{slug}/craft/agent-access?chat_id=…` and `crewship craft agent-access <page> --chat <chat>` say `allowed`, or the same `reason` the agent would be told (`feature_off`, `agent_policy`, `not_attached`, `holder_human`, `engine_failed`) with a finer `detail` and who edits the Sheet now. It grants nothing; every agent call is still checked on its own. A chat run started with `artifact_agent_access_modes` off now gets `feature_off` instead of a bare `no_human_principal`. To someone who may read the latest revision it also names that revision (`head_version`, `saved_at`, `saved_by_name`), so the chat can say which version the agent would start from.
