- **Docs can be downloaded as Word documents.** `crewship doc export --as docx` and `GET /api/v1/pages/{slug}/document/export?format=docx` return the confirmed document as a `.docx` file with headings, lists, checklists, quotes, tables, links, emphasis and code blocks (math as its LaTeX source), with the same access as reading it; content Word cannot hold is refused with a reason.
