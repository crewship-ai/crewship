- **Chat messages can carry structured artifact references that bound an agent's run (#5317), behind the `artifact_agent_access_modes` flag, off by default.** A message's attachment chips (`metadata.artifact_refs`) are checked against the sender as an ordinary member before the message is stored, with one error for a missing, unreadable or foreign artifact. They are recorded with the message and bound to the run in the same transaction as its human principal; a database trigger refuses any other run-scope row. With the flag off nothing changes. Enforcement inside the run follows in later steps.
