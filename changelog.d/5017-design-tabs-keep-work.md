- **Two Design tabs no longer overwrite each other's unsent work in this browser (#5017).** With the connection down, each tab replaced the whole stored canvas with its own copy, so killing one tab lost what only that tab held. The stored canvas now keeps one entry per tab, each with the state its comparison started from, written as one step. Reopening combines the entries and shows any text the combination hides in the conflict notice. A tab removes only an entry it wrote or recovered, once the server holds it and any notice is stored, and a tab whose session ended adds to the stored canvas instead of replacing it. The new entries are a separate kind of row: drafts from earlier builds still open, and rolling back shows no draft rather than a Page that cannot be edited.
- **A wall clock change can no longer stall or disconnect a Design version save (#5017).** The sync pacing read the wall clock: a jump back held a save for as long as the jump, and a jump forward could trigger the server's 4429 close. Pacing now uses the monotonic clock, and a save ends within five seconds of the click, or at once when the socket or editor closes, with your work kept in the browser.
- **Confirmed sign-out no longer leaves a Design canvas behind (#5017).** A tab rewrote its stored canvas as it closed, so the row no longer matched what the sign-out had confirmed and stayed in the browser, encrypted. A tab now rewrites only work no store has carried. A change still being stored at that moment stays encrypted for its owner.
