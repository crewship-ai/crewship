- **Two Design tabs no longer overwrite each other's unsent work in this browser (#5017).** With the connection down, each tab replaced the whole stored canvas with its own copy, so killing one tab lost what only that tab held. The stored canvas now keeps one entry per tab, each with the state its comparison started from, written as one step. Reopening combines the entries and shows any text the combination hides in the conflict notice. An entry goes once the server holds it, and a tab whose session ended adds to the stored canvas instead of replacing it. Rows stored by earlier builds still open.
- **A wall clock change can no longer stall or disconnect a Design version save (#5017).** The sync pacing read the wall clock: a jump back held a save for as long as the jump, and a jump forward could trigger the server's 4429 close. Pacing now uses the monotonic clock, and a save ends within five seconds of the click, or at once when the socket or editor closes, with your work kept in the browser.
