- **Two Design tabs no longer overwrite each other's unsent work in this browser (#5017).** With the connection down, each tab replaced the whole stored canvas with its own copy, so killing one tab lost what only that tab held. Tabs now merge into the stored canvas under the cross-tab draft lock. When two tabs changed one text, the text that loses appears in the conflict notice, which is stored before the merge. A tab refreshes its pending mark with every canvas it stores, so confirming another tab cannot remove it, and a mark ahead of the stored canvas still gives the conflict check its base after a reopen.
- **A wall clock change can no longer stall or disconnect a Design version save (#5017).** The sync pacing read the wall clock: a jump back held a save for as long as the jump, and a jump forward could trigger the server's 4429 close. Pacing now uses the monotonic clock, and a save ends within five seconds of the click, or at once when the socket or editor closes, with your work kept in the browser.
