- **A crew's Bedrock account rule rewrote agents configured for another provider.** Creating or moving a Claude Code, Codex or other agent into a crew with a Bedrock account rule turned it into an OpenCode/Bedrock agent, and an agent leaving such a crew lost its model. The rule now applies only to agents on Bedrock or with no provider chosen; a Bedrock model the crew's account does not permit is refused on create and move; unsharing the account from a crew removes that crew's rule; refused AWS calls no longer appear as usage of unknown size; an agent's page no longer fails when its credential readiness cannot be computed.
