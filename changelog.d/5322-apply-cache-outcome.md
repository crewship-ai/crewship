- **A routine whose conditional agent step was skipped no longer ends FAILED "no outcome reported".** The outcome check now counts only agent and nested-routine steps that actually ran; an agent that ran without a hand-off still fails as before.
- **Two crews provisioning the same devcontainer feature no longer fail with `lstat …/.crewship-digest: no such file or directory`.** Pulls of one feature cache entry are serialised, waiters reuse the finished entry, and a cancelled provision stops waiting.
- **`crewship apply` reports problems at dry-run instead of mid-apply.** A SKILL.md the server would refuse and an `env_refs` name that exists neither in the manifest nor on the server now fail the plan; a credential created with `crewship credential create` is accepted without being declared in the manifest.
- **`crewship apply` no longer fails with HTTP 409 when it writes crew files right after updating the crew.** It waits up to about 30 seconds for the recycled container and shows the server's error message when it still refuses.
- **`crewship apply` and `export` leave crew-inherited credentials alone.** They are no longer planned for deletion (a silent no-op that never converged) or exported as per-agent grants, and `crewship credential unassign` explains that a crew-delivered credential is stopped by unlinking it from the crew.
