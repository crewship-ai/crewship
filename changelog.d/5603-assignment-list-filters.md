- **The Chat side panel's "Now" section no longer misses an agent's older queued work in a busy crew.** `GET /api/v1/crews/{crewId}/assignments` takes `?assigned_to=<agent id or slug>` and `?status=<comma list>`, filters before `limit`/`offset`, and publishes the filtered total in `X-Total-Count` (with `X-Limit`/`X-Offset`). The panel used to read the crew's 100 newest rows and filter them in the browser; it now asks the server for the agent's `PENDING`/`QUEUED` rows. `crewship crew status` gains `--assigned-to` and `--status`. ⚠️ **Behaviour change:** an unknown `status` value is now `400` instead of being ignored (#5603).
