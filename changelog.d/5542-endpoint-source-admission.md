- **An authenticated `ENDPOINT_URL` local-model endpoint now works through the sidecar proxy.** Its proxy entry carried a synthetic `local-model-endpoint` ID, which host admission could never match, so every model call through such an endpoint failed with HTTP 403 `credential scope unavailable` before reaching the endpoint. The proxy entry now carries the real Vault credential ID and a revision of its encrypted value, replaces the raw endpoint entry, and stays out of the agent environment. Admission re-resolves the endpoint the agent would select, inside the admission transaction, and requires the same ID and revision, so a rotated, revoked, expired or foreign endpoint is refused. Audit and cost attribution use the real credential. The workspace-default endpoint no longer selects a `CREW`-scoped row that is not linked to the agent's crew, or a row linked only to other crews.
