- ⚠️ **Behaviour change: a native Craft agent task starts only from a saved instruction (#5009).** The CLI and task API accepted any of your chat messages, so an instruction had already run as an ordinary turn, and the agent's reply reached its logs and the journal, which other members can read. `crewship craft task instruction AGENT TEXT` now saves the text in a new private chat without a turn, as the editor does, and `craft task start` and `POST /craft/tasks` refuse anything else with 403. The saved instruction is shown only in the chat's transcript: later turns, the Keeper judge and its audit prompt, the operator model, conversation search and shared chats no longer receive it. `chat retry` and the browser's Regenerate and Edit and resend refuse it, and `recap` and the "from this conversation" action forms leave it out.
