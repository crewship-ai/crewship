- **Installed native tools were missing from interactive terminals.** The terminal uses shared native paths, including persistent crew tools, and reads only PATH from container metadata. Metadata failures fall back to shared/system paths so the terminal can still open. Agent-run credentials are not copied; new images restore native paths for POSIX login shells and verify global mise installations outside project configuration.
- **Image cache migration:** the generated login hook invalidates crew image cache keys once. The next provision builds a new crew image even with unchanged declarations; underlying feature/Docker layers may be reused. Running containers retain their image until normal activation.
