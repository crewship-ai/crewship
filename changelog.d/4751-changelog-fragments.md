- **Release notes can be added as their own file, so queued PRs stop conflicting on `CHANGELOG.md` (#4751).** Every PR used to add its note at the top of `## [Unreleased]`, so any two PRs in the merge queue conflicted there and were re-merged and re-run through full CI. A PR can now add `changelog.d/<PR-number>-<slug>.md` instead; the Changelog Guard accepts a new non-empty fragment or an `## [Unreleased]` edit (empty fragments, and edits to existing ones, do not count), CI routes fragments like `CHANGELOG.md` prose, and `scripts/changelog-collect.py` folds the fragments into `## [Unreleased]` at release time (`RELEASING.md`).
