- **An artifact card without a preview now says so (#5154).** The library has no safe preview image of an artifact's version yet, so its cards, Home and the Preview panel draw a picture of the kind (dashboard bars, a slide, a page). That drawing now carries a visible "<Kind> · no preview" label, so it is not mistaken for the content. The library still never fetches the content or runs an artifact's own code to draw a card.
