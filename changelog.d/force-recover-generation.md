- **`crewship recover --force` over an existing data directory could leave a half-replaced installation.** It now stages and validates a complete new generation next to the old one on Linux, swaps the two atomically and keeps the previous directory (reported as "Previous data directory (retained)"), with a documented rollback. After the swap it re-checks the database, foreign keys, memory versions, files and encryption keys. Symlinks in the existing directory are copied as links and never followed, a stale socket left by a crash is left out and named in the report, and every entry that blocks the copy (hard-linked files, special files, mounts) is listed before anything is copied. ⚠️ **Behaviour change:** forced recovery is Linux only, and a directory with a hard-linked file, a special file or a nested mount is refused.
