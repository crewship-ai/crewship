- **`crewship page grant` and `page revoke` now act in the workspace named by `--workspace`.** The commands had a local boolean `--workspace` that hid the global flag, so they could only reach the configured workspace. ⚠️ **Behaviour change:** the subject "everyone in the workspace" is now `--everyone`. The old boolean form is refused with exit 2 and changes nothing, including explicit values such as `--workspace=false`.
- **`crewship craft initialize` can now create a Sheet.** `--application sheet` starts an empty artifact as a Sheet. Word stays the default, and an unknown application exits 2.
- **Restoring a Craft version that does not exist now says so.** The lease holder gets 404 `native version not found` and exit 3 instead of 403 and exit 4, which read as a permissions problem.
- **`crewship page artifact` usage errors now exit 2.** A missing, unknown or invalid flag or an unusable manifest exited 1, the generic failure, so a script could not tell a mistake in the command from a server problem. ⚠️ **Behaviour change:** scripts that test for exit 1 on these local errors must test for 2.
- **`crewship craft connect` passes `attemptId` on save, import and reconcile.** A lost save can now get the definite 410 "did not commit and never will" on the connection that made it, instead of staying unconfirmed.
