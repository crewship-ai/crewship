- **A restricted member can open a shared artifact from its ID link (#5135).** Links such as `/artifacts/<id>`, older `/pages/@<id>` links and native editor links now open the artifact's shared actions for a restricted member who has been given them, the same as the slug link does. An ID the member was not given, or one that does not exist, still shows the same "not part of your access" message, and the address is never sent to the server to decide access. The restricted catalog entries now include the artifact's `id`, which `crewship context pages` also prints.
