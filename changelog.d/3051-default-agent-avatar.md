- **Agents created through the CLI, API, onboarding, crew templates, hires or Captain no longer start without a stored avatar seed.** Only the web dialog sent an `avatar_seed`, so every other path left it empty. The server now stores the agent's slug as the seed whenever a create does not name one, which keeps the face stable if the slug is renamed. `avatar_style` is unchanged: NULL still means "follow the crew's style, else Voxel Bot". The server cannot draw a render, so agents in a non-voxel style still need the existing "Store missing avatars" backfill to get a stored render; existing agents are unchanged.
