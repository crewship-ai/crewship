- **Agents created through the CLI, API, onboarding, crew templates or Captain no longer start without a pinned face.** Only the web dialog sent an avatar seed and style, so every other path left both empty and the agent's face depended on the crew style and the installed generator until someone ran "Store missing avatars". The server now stores the dialog's defaults (seed = the agent's slug, style = `voxel-bot`) whenever a create does not name its own. The server still cannot draw a render, so agents in a non-voxel style still need the existing backfill to store one; existing agents are unchanged.
