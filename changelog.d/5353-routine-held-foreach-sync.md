- **A synchronous routine run no longer hangs on a held action inside `foreach` (#5348).** `crewship routine run` without `--async` now returns `WAITING` with the item's approval token as soon as a held `crewship` action inside `foreach` starts waiting, and the run continues on the server; before, the CLI blocked until the decision and a client that went away cancelled the run. Interrupting a synchronous run before anything waits still cancels it. A MANAGER deciding a held action now reads "a held routine action needs a workspace OWNER or ADMIN to decide it" (403), and approving a closed waitpoint says why it is closed (run cancelled, timed out, already decided) instead of "already decided or expired".
