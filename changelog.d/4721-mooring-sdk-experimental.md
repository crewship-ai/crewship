- **Experimental Mooring SDK entry point for Craft application authors (#4721).** `lib/mooring/sdk` is a new, separately imported TypeScript entry point with lease, save-status, recovery-offer and version-history helpers over the existing whole-native Craft and artifact project paths, plus the NoteCraft example application under `examples/mooring/notecraft`. It is experimental: no product code or external application uses it, NoteCraft is not shipped in the product, and there is no compatibility promise. The root `lib/mooring` entry is unchanged and does not re-export it; the SDK does not export the host's save lifecycle, private draft journal or admission client. Nothing changes for people using Artifacts.
