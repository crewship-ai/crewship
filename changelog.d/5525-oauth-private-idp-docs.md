- **The OAuth guide showed a private IdP that can never connect (#5525).** `docs/cli/oauth.mdx` used `gitlab.acme.internal` as its custom-endpoint example, but the token exchange and refresh go through the SSRF guard, which refuses private, loopback and link-local addresses whatever the crew's `allow_private_endpoints` says. The example now uses a public host, and the guide says plainly that a token endpoint must resolve to a public address and what `oauth connect` reports when it does not.
