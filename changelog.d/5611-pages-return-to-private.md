- **A shared artifact can be returned to its owner's personal space with the same Page ID (#5601).** `crewship page unshare <page>` (`POST /api/v1/pages/{slug}/return-private`) first lists every access that ends: people and crews, the folder, page grants, public links and agent mandates. A confirmation bound to that review then makes the Page private again in one step. Grants are deleted, so sharing again starts from nothing. Former readers are refused at once, and workspace owners and admins keep the audited read. Only the Page's owner may do it. It works for workbooks and HTML artifact projects, the types that can be shared again. Docs documents and native Word and Sheet documents are refused until they can be shared again (#5617), so that returning one is never one-way.
