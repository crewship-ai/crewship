- **A shared artifact can be returned to its owner's personal space with the same Page ID (#5601).** `crewship page unshare <page>` (`POST /api/v1/pages/{slug}/return-private`) first lists every access that ends: people and crews, the folder, page grants, public links and agent mandates. A confirmation bound to that review then makes the Page private again in one step. Grants are deleted, so sharing again starts from nothing. Former readers are refused at once, and workspace owners and admins keep the audited read. Only the Page's owner may do it. It works for Docs documents, workbooks, native Word and Sheet documents and HTML artifact projects.
