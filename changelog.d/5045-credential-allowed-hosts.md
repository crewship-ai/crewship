- ⚠️ **Behaviour change: credentials can carry human-approved hosts (#5045).** `crewship credential hosts` sets them, and only a signed-in OWNER or ADMIN can change them. A host-bound credential reaches a run only when the crew is restricted and its egress allowlist covers every host. Otherwise it is withheld on every delivery path and reported by `agent credential-readiness`, including on free-network crews. Routine http steps compare the real target host instead. This does not stop an agent holding a delivered token from sending it to any host the crew allowlist permits.
