- **A workbook you attach opens as a Sheet beside the chat.** Open it from the message, let the agent change it in that chat until you turn it off, and watch the agent's changes land in the open Sheet without handing it back first. A message sent while the Sheet is still opening, or while it failed to open, waits for you instead of sending the workbook as a plain file.
- **Your edits and the agent's merge instead of overwriting each other.** When the agent saves a version while you have unsaved work, its changes are replayed under yours; a cell you both changed keeps your value and is named on the chat card. When a change cannot be replayed you choose between keeping your work and opening the agent's version.
- **A change card says what the agent changed and how to take it back.** It names the cells and sheets, offers Show in Sheet and Undo, and for a change too large to undo says which version to restore from version history.
- **A message you send is never lost when the agent cannot run.** A message the server saved but did not run shows its reason with Send again; one the server did not save comes back to the composer with its text and files.
- **Ending a session with unsaved Sheet edits no longer leaves "Keep this tab open" on screen.** The tab tries to keep your draft again before it asks you to stay, and it leaves once the draft is safe.
- **The chat shows one clear sign that the agent is working**, a pulse on its face, with human names for the steps of a Sheet change instead of internal tool names.
