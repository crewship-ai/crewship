- **Native mise lock resolution works for crews with npm-backed tools on mise lockfile v4.** mise 2026.11 writes npm/aube auxiliary locks beside a global lock under `locks/` and references that path from `mise.lock`; the bundle contract only accepted `.mise/locks/`, so `crew provision lock-resolve --crew` returned 502 for any crew with, for example, OpenCode. Both layouts are now accepted, cleaned and packed with the same path and symlink rules (from `locks/` only directories `mise.lock` references), and the server logs the resolver error.
