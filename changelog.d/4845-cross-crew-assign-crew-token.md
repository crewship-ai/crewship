- **A lead can delegate across a crew link again (#4845).** A crew's sidecar sends `/assign` with the linked crew as the target. The server refused every target crew that was not the sidecar's own crew, so the crew link check never ran and cross-crew delegation failed for every crew. The crew token now binds the caller. The acting agent must be in the token's crew. The chat must be in that crew too, unless the server derived it from the caller's running assignment, as for a sub-agent working on its lead's chat. Whether the target crew can be reached is decided by the crew link. A crew in another workspace, or an unknown crew, gets the same refusal as before.
