- **The PRD RC gate no longer reports a required ID as passed while one of its tests failed (#4767).** When two tests emit the same required ID (for example the API and browser tests of `A.craft.read-revoked` or `A.craft.write-revoked-*`), the gate kept only the most recently finished row, so a failed test that finished first was hidden by a later passing one. Each test now keeps its own latest row (a rerun still supersedes that test's earlier attempt) and the ID takes the worst of its tests.
