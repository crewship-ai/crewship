- **Agents can propose changes on schema 4 Docs, and people accept or reject them (#5137).** A schema 4 targeted chat message now lets the agent propose a new text for one paragraph or heading at a time; the Doc does not change until someone with edit access accepts the proposal in the Docs view's **Proposals** tab or with `crewship doc proposal-accept`. Formatting on unchanged text, code block languages, quotes and task lists are kept. On a shared Doc the agent needs a `write` grant naming it; a read or crew grant is not enough, another person's private Doc is never reachable, and restricted members get no proposal controls. The Docs view's **Propose** agent mode and the Proposals tab appear only where the server serves proposals. New: `crewship doc proposals`, `doc proposal`, `doc proposal-accept`, `doc proposal-reject`, `doc draft propose` and the MCP tool `doc_draft_propose`; migration `20261108204553_document_proposals`. Schema 3 drafting is unchanged.
