- **Pending Docs edits survive a server restart (#5163).** The Docs editing epoch now names the content you edited instead of the server process: a backend or Docs engine restart keeps it, so a browser replays edits it had not yet confirmed instead of holding them as a draft. A History restore, a schema upgrade or a restore from backup still changes the epoch; a backup restore gives the database a new identity, so edits made before the restore are never replayed onto restored content.
