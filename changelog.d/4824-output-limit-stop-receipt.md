- **A chat turn stopped at the output cap no longer holds its agent until the crew container goes away (#4824).** When a protected host run reaches the output limit or hits a capture error, the run is stopped through the same provider stop as a cancellation. That stop records a whole-process-tree receipt bound to the execution. Until now, only cancelled runs could settle on that receipt. A turn ended by the output cap in a long-lived crew container stayed in `needs_reconciliation`, and kept its agent and a server chat slot, until the container disappeared or an operator ran `crewship work resolve`. The receipt now settles these runs too. Without it, they still wait for the whole runtime to be gone.
