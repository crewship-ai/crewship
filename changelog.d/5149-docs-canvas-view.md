- **Docs Canvas view (#5149).** A schema 6 Docs document offers Canvas next to Page in the Artifacts library: the same document laid out as cards you can pan, zoom, fit, place, move and resize. A move changes only where a card sits, never the Page text. People with read access can open Canvas and look around but not change it; a card's comment badge opens the same thread as the Page. Older documents keep Page only.
