- **Docs Canvas view and Enable Canvas (#5149).** Every Docs document offers Canvas next to Page in the Artifacts library. On an older document the first switch asks "Enable Canvas for this document?" and, once a person with edit access confirms, upgrades it (`POST /api/v1/pages/{slug}/document/upgrade`, `crewship doc upgrade`): text, formatting, versions, comments and open proposals stay; a retry never upgrades twice; agents cannot upgrade. Canvas lays the same document out as cards you can pan, zoom, fit, place, move and resize; a move never changes the Page text. "Remove from canvas" takes only the card off; "Delete block…" deletes it from the Page and the Canvas after a confirmation naming the threads it detaches. Notes live on the canvas only. Undo and Redo take back only your own canvas changes. People with read access can look around but not change it; a card's comment badge opens the same thread as the Page.
