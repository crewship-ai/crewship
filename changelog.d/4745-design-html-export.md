- **A Design version can be exported as one portable HTML file (#4449).** `GET /api/v1/pages/{slug}/design/export?format=html&version=N` and `crewship page design export <slug> [--version N] [-o file]` render every screen of an immutable saved version (never the live canvas) server-side into a single self-contained file: inline CSS, embedded `data:` images, no script, no network references, a `default-src 'none'` policy, escaped text and prototype links as in-page `#screen-N` anchors. Without `--version` an editor gets the latest saved version and a Read or Comment audience the shared version; other versions answer exactly like the Design read, and a workspace administrator's foreign export is audited. The file name and header name the version, the same version under the same Design name always produces the same bytes, and an export over 8 MiB is refused with `413 design_export_limit`. The editor's **Export HTML** button is behind `NEXT_PUBLIC_ARTIFACTS_DESIGN_EXPORT` (default off); the route follows the existing `artifacts_design` flag. No migration.
