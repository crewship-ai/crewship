- **Main CI no longer turns red on Go Race combined duration when no test fails (#4761).** The internal/api combined-budget alarm compared the summed seconds of six partitions with the unsplit package's 2026-09-14 runtime (2300 s). That variable also set the per-partition hang timeout. The report now uses its own `RACE_API_COMBINED_BUDGET_SECONDS` (5000 s) and the CLI report uses `RACE_CLI_COMBINED_BUDGET_SECONDS` (3400 s), each the median of the 2026-11-01 runs rounded to the nearest 100 s. The timeout basis is now named `RACE_API_TIMEOUT_BASIS_SECONDS` and stays at 2300 s. The 1.6x alarm, the job caps and the warn-on-PR / fail-on-push policy are unchanged.
