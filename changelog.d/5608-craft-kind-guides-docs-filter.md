- **`crewship artifacts kind-guide` now lists native Word and Sheet.** The guide catalog (`GET /api/v1/artifact-kind-guides`, the agent `artifact_kind_guide` tool) skipped the Craft kinds and answered `404` for `word` and `sheet`. It now serves `word` (application `wordcraft`) and `sheet` (application `gridcraft`) guides that say an agent cannot create one, works on one only inside a confirmed native Craft task with the `crewship-craft` tools, and declare `create` and `comment` unsupported; `wordcraft` and `gridcraft` are accepted as aliases.
- ⚠️ **Behaviour change:** **`crewship page list --kind word` no longer mixes Docs documents with native Word.** The catalog `kind` filter (`GET /api/v1/pages?kind=`) called a structured Docs document (`has_document` without an `artifact_kind`) `word`. It is now `kind=docs`, and `kind=word` selects native Word (`artifact_kind: word`) only, as the web library shows them. Scripts that listed Docs documents with `--kind word` use `--kind docs`.
