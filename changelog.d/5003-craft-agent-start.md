- **Start an agent edit from the native Word and Sheet editor (#5003).** Until now only the API or `crewship craft task start` could start one. With native agents enabled, a person with write access can press "Upravit agentem", pick an agent, write the instruction and explicitly allow whole-document editing. The editor sends the instruction through a new chat with that agent, waits for the chat turn to end, then starts the existing task and shows its outcome in the task status panel, including a proposal when someone holds the document. No new endpoint; the control is absent while the editor is read-only, blocked or retiring its write.
