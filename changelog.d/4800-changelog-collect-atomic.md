- **An interrupted `scripts/changelog-collect.py` no longer loses release notes (#4800).** The collector deleted the fragment files before it installed the updated `CHANGELOG.md`, so a run stopped between the two (crash, kill, full disk) left deleted notes in neither place, and a rerun silently collected only what was left — or reported "No changelog fragments" with `CHANGELOG.md` unchanged. It now writes `CHANGELOG.md` atomically and durably first (staged file, fsync, rename) and deletes fragments only afterwards; a rerun skips notes already in `## [Unreleased]`, so each note ends up there exactly once.
