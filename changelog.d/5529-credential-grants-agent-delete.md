- **Deleting an agent revokes its credential grants (#5529).** Agent, crew and workspace delete remove the deleted agents' explicit grants and leases in the same transaction, each recorded as a `REVOKE` audit event, so `credential list` counts drop and a revived agent cannot inherit them. An upgrade migration revokes grants left by earlier deletes the same way (reason `agent_deleted_repair`). Credential material, bindings, crew links and other agents' grants are never touched.
