- **Only an artifact's owner delegates Edit to an agent (#5234).** Granting an agent `write` now requires owning the page: the owning user, or a member of the owning crew. A workspace admin can still grant an agent read or produce, manage every human and crew grant, and revoke any grant. An existing agent `write` grant issued by someone who does not own the page is shown as inert and authorises nothing until the owner issues it. `crewship page grant --agent <slug> --level write` from a non-owner exits 4, `page grants` reports `can_delegate_agent_edit`, and the Access form offers agent write only to the owner.
