- **Login shells keep declared mise pins first in new homes.** Provisioning rewrites the Debian/Ubuntu skeleton line `PATH="$HOME/.local/bin:$PATH"` in the image's `/etc/skel/.profile` and `/home/agent/.profile` so it only adds `~/.local/bin` when PATH lacks it; `bash -l`, postStart hooks and `zsh -l` in a newly seeded home then select the declared version over a stale home binary. Existing home volumes are not rewritten (docs give the one-line replacement). The script is part of the image cache key, so each crew image rebuilds once on its next provision.
