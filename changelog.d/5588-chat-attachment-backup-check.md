- **Backups no longer report chat attachments as missing, and `crewship backup drill` no longer fails `attachments_open` on them.** A chat attachment is stored at its `storage_key` in the agent's output tree, not in the content-addressed attachment tree. The backup and the drill both looked in the content-addressed tree, so every chat attachment marked the bundle `incomplete` (`attachment_missing`), and the drill reported it as unreadable although the file had been restored. Chat attachments are now checked at `storage_key` in the output store, with the key's path components validated (#5588).
