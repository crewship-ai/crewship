- **Design text layers take a text style (#5161, controls default off).** The server, the canvas and the HTML export accept and draw optional, closed text style fields on a text layer: `fontFamily` (`sans`, `serif`, `mono` system stacks), `fontWeight` (100–900 by 100), `fontSize` (1–1000), `lineHeight` (0.5–5), `textAlign`, `textWrap` (wrap at the box width) and `overflow` (clip to the box). Any other value is refused with `400`, and a layer without the fields looks exactly as before. The **Properties** controls appear only with `NEXT_PUBLIC_ARTIFACTS_DESIGN_TEXT_STYLE=true`; a server from before this change refuses a Design that uses the fields, so enable the variable only once no rollback past this server is expected.
