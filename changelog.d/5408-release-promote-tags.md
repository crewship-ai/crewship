- **Release image promotion no longer fails with an empty tag list (#5408).** GitHub drops a job output that contains a secret's value. Because of that, the `docker` job's `tags` output reached `promote` empty for `v0.1.0-rc.2`, and the release image was never tagged. `promote` now computes the tags itself with `scripts/ci/release-image-tags.sh`, using the same rule: the full version always, `vX.Y` and `latest` only for stable `vX.Y.Z`. The craft package pins are read from the committed catalog, which the build must reproduce. The only value still passed between jobs is the image digest.
