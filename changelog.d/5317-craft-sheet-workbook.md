- ⚠️ **Behaviour change:** **A Sheet the agent may change is the revision you saw.** A chat message's `artifact_refs` entries may carry `version`; a Sheet saved again after you attached it is refused as `consent_stale` before the agent starts.
- **A busy Sheet engine waits before it says busy.** When the server already has its two Sheets open, an agent's change waits for its turn (at most 45 seconds, and at most a third of the time the call has left) and only then answers `busy`, with nothing changed; the agent says so and retries the same change.
- **A failed Sheet initialize names its step.** The server's own failures answer 500 with `code` `server_<step>` instead of "access denied", and the log names the step and error class without document content.
- **A Sheet can be kept as your own .xlsx or .xlsm file.** Import and every save keep the parts the editor does not change (VBA projects, signatures, custom XML) byte for byte; a save that would lose one is refused with `fidelity_loss` and nothing is stored. A changed signed workbook keeps its signature, which no longer matches, and the person is told.
- **An agent can change a Sheet while you have it open.** Beside your open editor the agent may only write values (`cell.set`, `range.setValues`, `range.clear`); anything else, a change it could not undo, or a Sheet held by another person answers `holder_human` and changes nothing.
- **An agent's change can be undone cell by cell.** The server keeps the values the change replaced; `POST …/craft/document/undo` puts back only the cells nobody touched since and answers how many came back (`restored`) and how many were kept (`skipped`). A change whose old values could not be kept whole is marked not undoable.
- **A message is never lost when the agent cannot run.** In a private chat, a message sent while the agent is busy, waiting for approval or without a working environment is saved, marked as not run with the reason, and can be sent again.
