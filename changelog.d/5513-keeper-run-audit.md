- **Keeper decisions retain their calling run (#5513).** Verified sidecar run identities are recorded in immutable Keeper request attribution, decision history and Vault Activity. Later human decisions keep the original agent and run. Approval consumption and request admission commit together; unavailable runs are refused before optional lease issuance, and access fails closed if its decision audit cannot be persisted. `KEEPER_DECISION` is policy evidence and does not update `last_used_at` or claim successful authentication.
