- **A busy agent is reported as busy, not as a failed run (#4881).** When the agent's chat work slot is held by a previous or recovering turn, `POST /internal/runs` returns 429 with code `chat_capacity_unavailable`, and the chat stream shows "The agent is busy: it is still finishing or recovering a previous turn. Try again shortly." instead of "failed to start a durable run". The error event carries the code in `metadata.code`; `crewship run` prints the message.
- **The generated OpenAPI 3.0.3 document no longer uses the 3.1 keyword `propertyNames` (#4630).** The decision answer `values` maps keep their value schema and carry the key pattern as the vendor extension `x-crewship-property-names`; generic 3.0 tools do not enforce that pattern, the server still does. A guard test fails if any 3.1-only keyword returns.
- **Case-variant devcontainer account options are refused (#5338).** `USERUID`, `Username` and similar spellings next to the common-utils account options would have set one build variable twice; the error now names the key as written. Account values are stored trimmed.
