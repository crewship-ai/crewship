- **An edit typed just before leaving the page is no longer missing from the restored draft (#4823).** Project source, comment and Design drafts are sealed and written to IndexedDB asynchronously; a navigation or tab close within a few hundred milliseconds of typing ended the page before that write committed, and the draft came back without the last edit. On `pagehide`, a hidden tab and `beforeunload` the newest uncommitted edit is now encrypted synchronously with a single-use keystream under the same per-person, per-Page draft key and kept in localStorage (never plaintext); the next load opens it with the usual same-person authorization and re-seals it into IndexedDB. ⚠️ **Behaviour change:** when such an edit cannot be captured (no key prepared yet, larger than 2 MiB, a running recovery merge, refused storage), the browser now asks before leaving the page.
