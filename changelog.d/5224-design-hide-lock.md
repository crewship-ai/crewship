- **Design: hide and lock layers (#5218).** Each Layers row can hide a layer, so it is not drawn or exported, or lock it, so it stays visible but a click or drag on the canvas leaves it alone. Both are stored in the document and survive a reload. The controls are behind `NEXT_PUBLIC_ARTIFACTS_DESIGN_HIDE_LOCK`.
- **Locked Design properties remain read-only.** Name, geometry, fill, text, links and order controls honor an inherited layer lock as well as canvas gestures and deletion. The controls remain off in main/release; dev2’s declared profile requires a compatible backend before activation.
- **A peer lock or hide retires active Design gestures.** Current document flags, including parent flags, gate move/resize and cancellation; unlocking during the same press never resumes its stale geometry.
