- ⚠️ **Behaviour change: Ctrl+S without a content change no longer creates a version in Word and Sheet (#5075).** It used to store another version of identical bytes, which cost history quota and added a history entry. Ctrl+S now confirms the saved version and sends no save; `craft/document/save` answers an identical save at the head with `unchanged: true` and the existing version, and writes and charges nothing, including for an agent change that leaves the document as it is. A repeat of an exact committed save returns its original receipt. While a save is unconfirmed, Ctrl+S first looks up the original attempt, and only a server answer that it never committed lets it save again. Changed bytes, and the same bytes as an older version, still save. A tab opened before this release shows "Výsledek nepotvrzen" after such a Ctrl+S until it is reloaded; it creates no duplicate.
