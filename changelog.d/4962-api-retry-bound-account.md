- **Retire retries within an API invocation after an observed account change.** The client stops that invocation before a retry or its own authentication-expiry signal, including account ABA; workspace-only changes keep global requests working. Appearance preference queues also retain pending writes per account/server, retire old timers, and leave unknown legacy queues inert. Activating another account does not upload the browser's existing look as a new choice. This covers the observed client binding and the appearance caller; other callers that initiate fresh requests, cross-tab/shared refresh ownership, refresh-cookie policy, cookie changes before binding, response-body privacy and already committed requests remain outside this guarantee.
