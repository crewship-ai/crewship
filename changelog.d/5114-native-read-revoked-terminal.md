- **Word and Sheet: losing read access while editing access is being taken away no longer leaves a browser draft behind (#4721).** If the server refused a save because read access was gone at the same moment the editor's write access was being retired, the refusal could be dropped. The draft then stayed in this browser's private store, reported as captured. A read refusal now always erases the Page's drafts first. The save lifecycle ends in its own `revoked` state, and a pending Ctrl+S or flush fails with `read_revoked`.
