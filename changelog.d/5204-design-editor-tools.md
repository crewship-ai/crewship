- **Design editor: resize, keyboard editing and layer order (#5201).** A selected layer has eight handles to resize it, and Escape or a cancelled pointer puts the box back. With a layer selected, the arrow keys move it by 1 px (Shift: 10), Delete or Backspace removes it, and `]`/`[` (with Ctrl/⌘: to front/back) change its stacking order. **Properties → Order** offers the same order actions. A comment whose layer was deleted now says so instead of pointing at nothing. A live reorder that meets a concurrent delete of that layer or its screen no longer leaves the reordering browser refused: the server drops the stale order entry.
