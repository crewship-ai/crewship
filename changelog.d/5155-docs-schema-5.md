- **Docs content schema 5 adds underline, text colour and highlight (#5155).** The colour of both is one of eight palette names (gray, red, orange, yellow, green, blue, purple, pink); the document stores the name, never CSS, and light and dark themes each show their own readable shade. Schema 1-4 documents load, validate and hash unchanged; a document becomes schema 5 only by an explicit `"schema": 5` initialize or the human-only engine upgrade, which now always goes to schema 5. Markdown export writes `<u>`, `<span data-text-color>` and `<mark data-highlight>`; Word export writes native underline, colour and shading. An editor that does not know schema 5 opens such a document read-only with "This document needs a newer editor". Agents still draft only schema 3.
