- **An agent killed at its step timeout stayed busy for ever, and its run, plus runs of deleted agents, stayed `RUNNING` (#5510, #5511).** When a detached run's tmux session was the last one in the container, tmux exited its server and every later probe answered "unknown", so the detached hold never released the agent (`agent busy: a previous run's detached exec is still alive`). A missing server now counts as absence only when the client reports no server and the container's process table, read without `hidepid`, holds no tmux process. A hold that confirms its runtime gone now records the run as failed (`agent.run.failed` audit row, `run.failed` with reason `detached_exec_confirmed_gone` in `run list`/`now`), and a periodic pass ends runs of deleted agents that no runtime can still execute (`run.cancelled`, reason `agent_deleted`). Durable work attempts keep their own outcome.
