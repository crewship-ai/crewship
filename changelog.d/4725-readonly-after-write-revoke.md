- **Losing only write access on an open Word or Sheet document keeps it open read-only (#4348).** When an editor's Page write permission is removed while read remains, the server retires the writer admission with `session_retired` `reason: "write_revoked"`, `draft: "retain"`. The editor then shows the current document read-only under a fresh read admission, says that write access was removed, and offers the unsaved local draft for compare or copy instead of disconnecting. The old admission and lease generation stay refused for every write path, also after a re-grant. Losing read access still stops all delivery.
