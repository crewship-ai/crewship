- **Every artifact now has one address, `/artifacts/<id>`, and old Pages links lead there.** With the Artifacts library in the web build, `/pages/<slug>`, `/pages/@<id>`, `/pages?ref=<id>`, `/pages/<slug>?artifact=1[&version=N]` and `/pages/craft/editor?page_id=<id>` resolve the page once and replace themselves with `/artifacts/<id>?workspace_id=…` (keeping a pinned project version); `/pages` opens the library. The server now returns the canonical address for a created document (`crewship doc create`) and in the agent project tool's `page_path`; without the library, `/artifacts/<id>` opens a project in the Pages project viewer and any other kind in its Pages detail. `/p/<token>` is unchanged. ⚠️ **Behaviour change:** `NEXT_PUBLIC_PAGES_OPEN_ARTIFACTS` is removed; `NEXT_PUBLIC_ARTIFACTS_LIBRARY` alone now turns on the redirects.
