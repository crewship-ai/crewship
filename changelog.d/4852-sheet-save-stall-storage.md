- **A Sheet or Word document no longer stops saving after one slow browser-storage write (#4852).** If the browser's local draft storage answered late after a save the server had already committed (for example after the page froze for a few seconds), the editor blocked every later autosave and Ctrl+S while the person still held editing. The status stayed on "Neuložený koncept" and nothing was sent. The block now lifts as soon as the local draft copy is written again. The editor retries once by itself, and the original save's confirmation still reaches the editor, so the status returns to "Uloženo" without a duplicate version. While storage keeps failing, the status reads "Neuložený koncept · úložiště prohlížeče neodpovědělo" and nothing is sent without a local copy. Conflict, quota and access refusals still stop saving as before.
