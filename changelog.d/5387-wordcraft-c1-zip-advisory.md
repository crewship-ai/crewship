- **The release source CVE scan failed on `zip` 3.0.0 in the WordCraft C1 engine (#5387).** The opt-in C1 engine helper and its browser harness locked the Rust `zip` crate at 3.0.0 (GHSA-m665-v7pm-7grj critical, GHSA-q7v9-x93c-xqv3, GHSA-8hxf-qr8p-62x4), so the release workflow's critical-cutoff Grype scan failed. A separate pinned dependency patch moves the pinned WordCraft revision to `zip` 9.1.0. ⚠️ **Behaviour change:** in the C1 engine's DOCX reader, an entry that inflates past its declared size is now skipped with a warning, and so is an entry whose name cannot be decoded. The engine identity and the qualified command catalog are unchanged. This PR does not change the shipped Word craft package (`tools/craft-components`, upstream WordCraft b0fb5cb). That package still locks `zip` 3.0.0 inside its own upstream build, tracked in #5388. It is not reachable there: WordCraft uses only `ZipArchive`, with no `ZipStreamReader`, no `extract` and no `aes-crypto`.
