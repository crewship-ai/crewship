- **Word and Sheet are available out of the box on nightly builds.** The nightly binaries and image used to be built without the Word and Sheet packages, so the Applications page showed them as missing on a nightly. The nightly now publishes the signed pair of an earlier release next to its archives, trusted by pins in the binary and listed in the signed checksums. The run fails, with the reason, if the pair is missing, changed, signed by another workflow or does not match the nightly's catalog. Installations without internet access can install the two files with `crewship admin instance applications install --file`.
