- **Unsaved project source and comment drafts from before Page-ID keys are offered again (#4827).** Builds before #4628 kept these drafts in the browser under the Page address (slug); the current build never read them, so the work was invisible. Opening the project now shows such a draft as an older draft that may belong to another Page (a slug can be renamed or reused). It is never applied or deleted automatically: the person chooses to use it here, which stores it encrypted under the Page ID and only then removes the old copy, or discards it. Only the account that typed it can see it; other accounts' copies are still removed on account change and sign-out.
