A workspace admin, an Edit grantee or an agent that saves a spec newly naming an agent producer gets 403. An edit that keeps a panel's producer unchanged is still allowed. A crew `produce` grant from anyone but the owner gets 403 (CLI exit 4), and the Access form offers non-owners only `read` and `write` for a crew. Migration `20261109152536_agent_data_delegation_owner_only` reads who designated each stored agent producer from the page's version history and ends every agent producer designation and crew `produce` grant the owner did not make. Designations and grants also end when the page changes owner, the designator leaves the owning crew, or the owning crew is deleted or moves workspace. Each ending writes an audit entry, `page.agent_producer.retired_not_owner` or `page.agent_grant.retired_not_owner`. A panel whose agent producer ended shows the reason as its fault, and the grants list shows the reason for a crew grant. Nothing revives them: the owner grants the agent `produce` or names the producer again. A page an agent creates for its own crew has no human owner behind its agent producers, so they push only once a member of the crew grants the agent `produce`.
