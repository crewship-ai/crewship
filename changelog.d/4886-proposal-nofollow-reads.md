- **Approving or diffing a staged skill or memory proposal no longer follows a link the crew planted (#4882).** A crew can write its own `.proposed` directories, so a proposal file or one of its parent directories could be replaced by a symlink pointing at another crew's files or host files, and approve or diff would read through it. Those reads now go through the same storage-root-pinned no-follow readers the listing already used. ⚠️ **Behaviour change:** a proposal that is a symlink, sits under a symlinked directory or is not a regular file is refused (skills approve and both diffs return 422; memory approve returns 500 and the proposal stays pending) instead of being read.
