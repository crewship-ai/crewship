- **Stopping a protected agent run in a shared crew container now ends the run and frees the agent (#4774).** A cancelled run could only settle once the whole container was gone, which never happens for a long-lived crew container, so the run stayed open and every later message to that agent was refused with "chat execution capacity unavailable". The stop now freezes and kills every process left in the run's session, confirms the session is empty, and records that receipt for the exact execution; the run then settles as cancelled. Without the receipt (an older sidecar, a member that could not be confirmed dead, or any forced end other than a cancellation) the run keeps waiting as before. A process that detached into its own session is outside this guarantee.
