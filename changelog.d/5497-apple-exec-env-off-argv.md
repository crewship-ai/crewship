- **On macOS (Apple container runtime), credential environment values no longer show up in the host process list (#5497).** Every exec passed its environment as `container exec --env KEY=value`, so any user on the Mac could read API tokens and other credentials with `ps`. Values now reach the `container` CLI through an anonymous pipe (`--env-file /dev/fd/3`), or, for values the env-file format cannot carry (line breaks, invalid UTF-8), through the CLI's own process environment with a bare `--env KEY`. Only variable names stay on the command line. The Linux Docker runtime is unchanged; it never used a host CLI.
