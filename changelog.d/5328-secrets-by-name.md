- **Routines can select one credential by name.** `{{ secrets.name.<NAME> }}`, `credential_ref: {type: name.<NAME>}` and `credentials_required: [{type: name.<NAME>}]` pick exactly that credential instead of the newest one of a type, with the same workspace, crew and host rules. A dotted `credential_ref.type` that is not `name.<NAME>` is now rejected at save instead of silently resolving nothing.
