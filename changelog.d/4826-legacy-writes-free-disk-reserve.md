- **Document and Slides saves now respect the free-disk reserve (#4826).** Legacy document writes (initialize, edit, checkpoint, checkpoint restore and schema upgrade) and Slides saves were counted against the workspace and instance storage budgets but skipped the free-disk check that artifact and native Craft writes run, so they could keep writing into the space reserved for database recovery and backup. They now run the same check before writing anything and, when free disk is below the reserve, answer with the same `413` `artifact_storage_quota` response. Nothing is written, every confirmed revision is kept, reads and exact retries still work, and the same save succeeds once space is freed.
