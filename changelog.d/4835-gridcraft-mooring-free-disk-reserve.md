- **GridCraft and Mooring saves now respect the free-disk reserve (#4835).** GridCraft workbook writes and Mooring document writes (legacy JSON documents, collaboration sessions and WordCraft commands) were counted against the workspace and instance storage budgets but skipped the free-disk check that other artifact writes run, so they could keep writing into the space reserved for database recovery and backup. They now run the same check before writing anything and, when free disk is below the reserve, answer with the same `413` `artifact_storage_quota` response.
