- **The library names each artifact by the same kind everywhere (#5152).** Pages now report `artifact_profile` (`design_system` or `interactive`) from the version you can read, and the list, kind counts, filters, preview, header and New artifact all derive one kind from it. A design system shows as **Design · Library**, and an interactive project, such as the 3D Showcase, shows as **App** instead of **Dashboard**, even when it keeps a data collection. Filtering or sorting by kind uses the library's kinds (Docs, Dashboard, Slides, Design, App, Word, Sheet); old `kind=` links still work.
