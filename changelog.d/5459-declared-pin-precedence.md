- ⚠️ **Behaviour change: declared mise tools win over older binaries in the persistent home.** Crewship-assembled environments (agent exec, routines, the terminal, child processes, zsh and the login hook) now put `/opt/mise/data/shims` before `/home/agent/.local/bin`, so a stale self-installed or self-updated CLI in the home volume no longer shadows the version a crew declares. The pre-existing default/seeded PATH literal is migrated at the next image build or container creation; any other operator order is kept. Bash login shells still run the user's own `~/.profile`, whose Debian default prepends `~/.local/bin`.
