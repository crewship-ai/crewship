- ⚠️ **Behaviour change: declared mise tools win over older binaries in the persistent home.** Crewship-assembled environments (agent exec, routines, the terminal, child processes, non-login zsh and the login hook) now put `/opt/mise/data/shims` before `/home/agent/.local/bin`, so a stale self-installed or self-updated CLI in the home volume no longer shadows the version a crew declares. Crewship's earlier generated run `/home/agent/.local/bin:/opt/crewship/bin:/opt/mise/data/shims` (stored by the default devcontainer and seeded crews) is migrated at the next image build or container creation; a PATH without that run keeps its order. Login shells (`bash -l`, postStart hooks, and `zsh -l` through `~/.zprofile`) still run the user's own `~/.profile`, whose Debian default prepends `~/.local/bin`.
- **One-time rebuild and recreate:** the order is part of the generated login hook and the runtime contract, so every crew image misses the cache on its next provision (feature/Docker layers may be reused), stopped crew containers are recreated on their next start, and running containers log runtime-contract drift until they are recreated through normal activation.
