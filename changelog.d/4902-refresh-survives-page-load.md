- **Creating a Sheet (or Word) from New artifact no longer signs you out (#4902).** On the exported build the library opened the new artifact by slug, which mounted the editor (its admission refreshes the session), and then reloaded the page as `/artifacts/<id>` mid-refresh. The new page presented the rotated-away refresh token, which the server treats as a replay and revokes. A just-created artifact now opens at `/artifacts/<id>` directly. Token refreshes take turns across tabs under a Web Lock and are sent with `keepalive`, so their cookies land even if the page goes away.
