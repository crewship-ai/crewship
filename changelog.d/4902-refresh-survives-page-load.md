- **Creating a Sheet (or Word) from New artifact no longer signs you out (#4902).** On the exported build the library mounted the editor, whose admission refreshed the session, and then opened `/artifacts/<id>` as a new page; the browser dropped that refresh's rotated cookies and the new page presented the old refresh token, which the server treats as a replay and revokes. The refresh is now sent with `keepalive` so its cookies land after the page is gone, and a refresh started in another page or tab is waited for (up to 3 s) instead of raced.
