- **CLI: `crewship workspace create` without `--slug` works (#5116).** The help promised a slug derived from the name, but the CLI sent none and the server refused the request with "slug must be 2-50 characters". The CLI now derives the slug like the web UI (lowercase, accents folded, other characters as hyphens, at most 50) and exits non-zero with a request for `--slug` when the name yields nothing.
