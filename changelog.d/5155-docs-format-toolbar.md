- **The Docs toolbar offers Heading 3, Underline, Text colour, Highlight and Clear formatting (#5155).** Bold, italic, underline and strike show a partly pressed state when only part of the selection has them; colour menus keep the selection visible while open and offer Default to remove a colour. New shortcuts: `Ctrl+U` (underline) and `Ctrl+\` (clear formatting, links stay). Underline, colour and highlight need a schema 5 document.
