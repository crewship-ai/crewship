- **Craft and WordCraft recovery drafts are handled correctly (#4666).** A recovered native draft whose bytes the server already holds is now removed from browser storage instead of reappearing after the next save and reopen. In WordCraft, a recovered local draft is no longer shown or downloadable after another person signs in, and a second storage-full stop appends to the existing local draft instead of overwriting it, also when the person changes while the stop is being stored; an older failed draft write no longer replaces a later stored stop.
