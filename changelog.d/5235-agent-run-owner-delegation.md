- **An agent run writes only what its human owns, or what the owner delegated (#5235).** An agent started from a chat can no longer use its human's workspace admin role or Edit grant to change someone else's Design or native Craft document. The agent writes only while its human owns the artifact, or when the owner gave it a `write` grant, and a running task stops when ownership moves. On a Design the run keeps its human's read access. People's own edits are unchanged. Slides, Dashboard data, Library projects and Document proposals already enforced this, and are now covered by regression tests.
