- **Slides has a presenter view with speaker notes in its own window (#5171, behind `artifact_slides`).** **Presenter view** opens a new window with the current slide, the next slide, the speaker notes and an elapsed-time clock, while the window you started from presents the deck for the audience, with a **Full screen** button. Moving in either window moves both; ending the presentation, or closing either window, ends it in both. The audience window never shows the notes. If the browser blocks the new window, the viewer says how to allow pop-ups for the site.
