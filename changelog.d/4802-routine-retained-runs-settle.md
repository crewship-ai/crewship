- **Protected routine step runs now settle after their output is captured (#4802).** A routine step reports its end by status alone, so its terminal receipt carries no exit code. When the protected run's captured output was replayed later with its real exit code, that missing code counted as a conflict, and the run stayed open, retrying every 30 seconds and logging "journal replay identity conflicts with stored content". A receipt without an exit code can no longer contradict a captured one. A receipt that recorded a different exit code, a foreign scope or a different terminal kind is still refused, and no stored journal entry or receipt is rewritten.
