- **A deleted agent's memory write that was still running no longer breaks the memory of a new agent with the same name (#4862).** If an agent was deleted and its name reused while one of its memory writes was in progress, that write could finish under the new agent's name. The new agent's memory writes then failed with "edited outside the memory contract", or the new agent's latest memory state was overwritten. A write that started before its agent's name was released now finishes under the deleted agent's archived name. If the memory state it read has changed in the meantime, the write is refused as a conflict instead.
