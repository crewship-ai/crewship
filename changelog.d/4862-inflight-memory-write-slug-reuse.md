- **A deleted agent's memory write that was still running no longer breaks the memory of a new agent with the same name (#4862).** If an agent was deleted and its name reused while one of its memory writes was in progress, that write could finish under the new agent's name. The new agent's memory writes then failed with "edited outside the memory contract", or the new agent's latest memory state was overwritten. Memory writes are now tied to the agent that made them, not only to its name. A write that started before its agent's name was released finishes under the deleted agent's archived name, and a write that has not been recorded yet when its agent is deleted is refused without changing the file.
