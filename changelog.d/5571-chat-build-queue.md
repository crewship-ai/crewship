- **Messages sent while a crew builds are no longer lost or merged (#5571).** Every message saved during the build now runs, one after the other in the order sent, and each one is counted in the chat when it is saved. A message that cannot run (failed build, chat busy for about a minute, server stopped, more than 20 waiting in one chat) leaves a visible reason in the transcript. A crash or kill of the server during a build still leaves the saved message unanswered; send it again.
- ⚠️ **Behaviour change:** a second message sent during a build no longer replaces the first; both run. A busy chat now waits for its live run instead of silently dropping the queued message.
