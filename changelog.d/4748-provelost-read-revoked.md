- **A lost save reconciled while write access ends no longer keeps the private draft after read access is gone (#4747).** When an editor's write access ended with a save whose reply was lost, the save coordinator checked that save on the server once more. If that check reported that read access had been removed too, the error was ignored and the fresh capture stayed in the browser's private draft journal. It now takes the same path as a save that reports read loss: the coordinator stops and the local journal is purged. Any other failure of that check still keeps the draft for comparison. In the current Craft editor the server reports read loss through the session event, which the editor host already handles; this closes the gap in the coordinator for any transport that reports it directly.
