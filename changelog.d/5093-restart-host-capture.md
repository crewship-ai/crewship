- **A server restart during an agent run no longer leaves the run without a recorded end (#5081).** With protected output capture, the service stop killed the capture helper before it wrote the run's result, and shutdown parked the work at once with "runtime stop could not be confirmed". Now the helper treats the service stop as its own stop: it ends exactly its run, records the stop receipt and the result, and exits. Shutdown waits, within its stop grace, for that confirmation before it settles the run, and recovery after the restart settles the parked run from the capture. Successful runs complete. A background run that was cut short keeps waiting for reconciliation, because it may have had external effects. Nothing is retried.
