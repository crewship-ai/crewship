- **A server restart during an agent run no longer leaves the work stuck in reconciliation and holding a slot (#5081).** With protected output capture, the service stop also killed the capture helper before it recorded the run's end, and shutdown parked the work without waiting for it. The helper now survives the service stop signal, shutdown waits briefly for the run's own result and settles it, and recovery after restart settles a shutdown-parked run once its capture is complete. A run whose end cannot be confirmed still waits for reconciliation; nothing is retried.
