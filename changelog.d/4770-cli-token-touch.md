- **CLI-token requests no longer open an extra database connection to record "last used" (#4770).** The `last_used_at` breadcrumb was written on every authenticated CLI request by a background goroutine racing the handler, so the pool opened a second SQLite connection (a full schema parse) just for it, and every request added a write transaction. It is now written on the request's own connection, at most once per minute per token per server process, with lock waits bounded to 250 ms (a failed write is retried after 5 s); the settings page still shows it to the minute.
