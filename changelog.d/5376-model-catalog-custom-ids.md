New defaults: Claude Code `claude-sonnet-5-5`, Codex `gpt-6.1-sol`, OpenCode `anthropic/claude-sonnet-5-5`. Housekeeping (keeper) slots now default to `claude-haiku-5-5`, or `gpt-6-luna` on OpenAI-only instances. Existing agents keep their stored model.
