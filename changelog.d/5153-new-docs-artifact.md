- **New artifact can create Docs (#5153).** When the server confirms the shared document format, **New artifact** offers **Docs**: enter a name, pick a folder or leave it unfiled, and **Create and edit** opens a blank document at its own address, listed under **Docs**. **Word** is now offered only when a Word editor (native WordCraft, the WordCraft SDK or commands) is confirmed, so a workspace that serves only the shared document format no longer offers a "Word" document that opens as Docs. The server still refuses a create from a Viewer or a member without `page.create`.
