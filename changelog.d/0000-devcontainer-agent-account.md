- **Crews built on a slim base image no longer fail with `sudo: you do not exist in the passwd database`.** The injected common-utils feature now uses the option names it actually reads (`userUid` / `userGid`), so the `agent` account is created at UID 1001 on every base image, not only on images that already had a user at 1000. A common-utils declaration that names another user or UID is refused at create, update and provisioning with the fix. An affected stored config builds a new image once, the next time it is provisioned (`crewship crew rebuild <crew>` does it now).
