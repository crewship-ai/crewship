- **An agent re-created with the name of a deleted agent can write its memory again (#4840).** The memory history of an agent is keyed by its name across the workspace, while its files live in its crew. A new agent that took a deleted agent's name in another crew inherited the deleted agent's last recorded memory state, so every memory write failed with "edited outside the memory contract". Freeing the name now moves that state to the deleted agent's archived name; memory history is unchanged.
