- New Docs start at schema 5, an explicit creation schema that no longer follows the newest schema. Agents propose on schema 4 and 5 Docs at the Doc's own schema, and accepting keeps underline, colours, highlights, dates and mentions; a proposal next to a date or mention is refused. `crewship doc read` lists what the Doc's schema supports in `capabilities`. Existing Docs keep their schema. (#5233)
- Upgrade note: the server and its bundled Docs engine must run the same release. A server that names the creation schema is refused by an older engine, and an older engine's proposals carry no schema and are refused by this server; the release binary ships both, so a normal upgrade is unaffected. (#5233)
