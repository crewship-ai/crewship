- **An expired sign-in no longer erases the draft of an open native Word or Sheet (#5005).** The event stream told the browser to delete the draft whenever the credential ended; it now does so only on proven loss of Page read. A draft kept through a read loss that arrived while disconnected is now erased once the server proves it, and an open editor stops showing content within 60 seconds even if both connections to the server stall. A handoff that gets no answer now ends at the 60-second admission deadline. `crewship page draft-key` gains `operation: "check"`, the proof a native draft uses. Losing Edit never erases a draft, even down to Comment. A confirmed sign-out now also erases the draft of an open native editor, which it used to keep when the editor stored a last snapshot during sign-out or another tab reported the session ended first. A newer draft written by another tab during sign-out stays, a draft kept after Edit became Comment is erased when Comment goes too, without a reload, and a restricted private owner keeps the draft.
