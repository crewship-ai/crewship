- **Slides decks can use bundled typefaces, gradients, rounded corners, arrows, icons and slide transitions (#5132, behind `artifact_slides`).** A Slides artifact may now set IBM Plex Sans or JetBrains Mono (shipped with Crewship, never loaded from elsewhere), bold and semibold weights, letter spacing, line height and font sizes up to 320 pixels; rounded rectangle corners; linear gradients between hex colours; straight lines with triangle arrowheads; about fifty outline icons picked by name from a fixed list (no author SVG); and a fade or push transition that **Present** plays unless reduced motion is on. The deck view and the PDF export draw the same additions. A deck that uses any of them is projected as `schema_version: 3`; every other deck keeps its schema-1 projection and PDF byte for byte, and the revision-based Slides API still stores only schemas 1 and 2. The seeded "Template Crewship Slides" deck uses the new profile.
