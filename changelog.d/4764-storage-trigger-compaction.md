- **Opening a database connection is ~25% cheaper again on instances with Artifacts storage accounting.** The 90 per-table storage triggers added in #4647 each repeated the full accounting logic with long size expressions, growing the schema SQLite parses on every new connection by ~110 KB; under `-race` that made nearly every API test ~1.4x slower and kept main's race budget alarm red. A new migration routes all of them through one `artifact_storage_charge` procedure; counters, clamping and `artifact_storage_quota` refusals are unchanged (#4764).
