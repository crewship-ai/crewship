- **Opening a database connection is cheaper again on instances with Artifacts storage accounting** (about 15% per open plus first query in a plain build; more under `-race`). The 90 per-table storage triggers added in #4647 each repeated the full accounting logic with long size expressions, adding ~110 KB to the schema SQLite parses on every new connection; under `-race` that made nearly every API test ~1.4x slower and kept main's race budget alarm red. A new migration routes all of them through one `artifact_storage_charge` procedure (storage trigger text 108 KB → 39 KB); counters, clamping and `artifact_storage_quota` refusals are unchanged (#4764).
