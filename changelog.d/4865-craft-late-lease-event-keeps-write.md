- **A Word or sheet editor no longer turns read-only after the browser freezes for a while, as long as you still hold the editing lease (#4863).** When the page's main thread stalled for longer than the 15 s lease lifetime, the lease renewals queued during the stall were handled late, with an expiry that had already passed. The editor treated that as lost custody and switched you to "Pouze čtení" with a local draft and "Převzít úpravy", although the server had kept renewing your lease. A late lease event with only a past expiry now asks the server first, as the periodic lease check already does since #4804. Write still ends at once when the event shows another holder, revoked write or edit rights, or a different generation, and within about 6 s when the server does not confirm custody or does not answer.
