- **Docs content schema 6 admits the Canvas surface (#5149).** Block placements, notes, shapes and connectors live in their own `surface:*` roots beside the page; a move changes only geometry, so page text, block hashes, Markdown and comment anchors are identical to schema 5. Schemas 1-5 keep refusing the surface and load, validate and hash unchanged; a document becomes schema 6 only by an explicit `"schema": 6` initialize or the human-only upgrade, which now goes to schema 6. The service validates the merged state on every save, and the surface has its own 512 KiB history share: a save past it is refused with 413 `surface_quota`, so merged copies can never push a document past its 1 MiB history limit. An editor that does not know schema 6 opens such a document read-only. Agents still draft only schema 3.
