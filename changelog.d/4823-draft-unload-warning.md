- **Leaving the page right after typing no longer loses a draft edit silently (#4823).** Project source, comment and Design drafts are sealed and written to IndexedDB asynchronously; a navigation or tab close within a few hundred milliseconds of typing ended the page before that write committed, and the draft came back without the last edit. ⚠️ **Behaviour change:** while any draft's newest edit is not stored yet, the browser now asks before leaving the page. The edit is not sealed synchronously on unload, because that would need an unauthenticated record or raw key bytes in the page; a tab killed without the prompt (for example by a mobile browser) can still lose the last edit.
