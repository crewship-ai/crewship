- **The access report no longer shows workspace admins as editors of someone's private output (#5583).** On a private artifact an ADMIN can only read it, with audit, and only the owner comments. The per-page access report and the access-change preview listed every ADMIN, and the workspace OWNER, with comment and edit. They now show read, plus edit for the OWNER only on the types the OWNER can actually edit (native Word and Sheet, Docs and collaboration documents).
