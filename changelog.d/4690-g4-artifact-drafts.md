- **Unsaved artifact drafts survive more storage failures, and a preference is never saved under another account (#4665).** A draft that only reached the encrypted localStorage fallback is removed when you save, discard or sign out, together with the older IndexedDB revision it replaced. A browser that blocks localStorage no longer stops Design drafts from loading from IndexedDB. A preference write that gets a 401 is no longer refreshed and re-sent (the refresh could finish after another person signed in); it stays marked unsynced and is sent again on the same account's next load. Drafts that builds before the Page ID keys stored under the slug are not adopted, because a slug can belong to a different Page by now.
