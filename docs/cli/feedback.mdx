# Feedback

Typed feedback is structured eval signal — `helpful` / `not_helpful` / `inaccurate` / `unsafe` / `edit` / `regenerate` bound to a message or trace. Distinct from chat reactions (social UI signal); feedback feeds evaluation and consolidation.

## `crewship feedback create`

| Flag | Type | Effect |
|---|---|---|
| `--message` | string | Message id the signal binds to (required). |
| `--signal` | string | `helpful` \| `not_helpful` \| `inaccurate` \| `unsafe` \| `edit` \| `regenerate` (required). |
| `--chat` | string | Chat id (optional). |
| `--trace` | string | Trace id (optional). |
| `--reason` | string | Free-text reason (optional). |

```bash
crewship feedback create --message cmsg… --signal not_helpful --reason "wrong file"
```

## `crewship feedback list`

List signals for exactly one of `--message` or `--trace`. Results include the workspace ID so rows copied by a fork can be distinguished.

```bash
crewship feedback list --message cmsg…
crewship feedback list --trace tr_… --format json
```

## `crewship feedback delete`

Remove a signal from a message in the currently selected workspace. The CLI includes its workspace ID in the DELETE request, so a fork's copy of the same feedback cannot cause an ambiguous delete.

```bash
crewship feedback delete --message cmsg… --signal not_helpful
```

## `crewship feedback preferences`

List your structured explicit preferences for one agent, including source feedback,
source revision, entry revision and processing status. These records use the existing
agent peers API; they are separate from daily peer-card Markdown.

```bash
crewship feedback create --message cmsg… --signal helpful --reason "Next time, keep answers concise."
crewship feedback list --message cmsg… --format json
crewship feedback preferences --agent agent… --format json
```

Catalogue v1 accepts exactly `Next time, keep answers concise.`,
`Next time, start with the conclusion.`, `Příště piš stručněji.` and
`Příště nejdřív ukaž závěr.` as voluntary future preferences on helpful/not_helpful
feedback. Other reasons remain feedback without inference.

## `crewship feedback edit-preference`

Correct your own entry using its current revision and an exact catalogue v1 reason.
The server reprocesses the new source revision asynchronously. A stale revision
returns 409; editing a withdrawn entry cannot restore it.

```bash
crewship feedback edit-preference --agent agent… --entry entry… --revision 1 --reason "Next time, start with the conclusion."
```

## `crewship feedback delete-preference`

Withdraw your own entry using its current revision. A durable tombstone prevents
pending work and daily Markdown rewrites from restoring that source.

```bash
crewship feedback delete-preference --agent agent… --entry entry… --revision 2
```
