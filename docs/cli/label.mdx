# crewship label

Manage workspace labels. Labels are shared across every crew in the
workspace and attached to issues via `crewship issue update --labels`.

```bash
crewship label <subcommand> [flags]
```

**Alias:** `crewship labels`

## Subcommands

| Command | Description |
|---------|-------------|
| `list` | List labels in the current workspace. |
| `create` | Create a new label. |
| `update` | Update a label. |
| `delete` | Delete a label. |

---

## `crewship label list`

```bash
crewship label list
```

**Output columns:** ID, NAME, COLOR, GROUP. `--format json` prints the array of
`{id, name, color, label_group}` objects. Any workspace member can list labels.

---

## `crewship label create`

```bash
crewship label create --name "Bug" --color "#EF4444"
crewship label create --name "P0" --color "#DC2626" --group priority
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--name` | `string` | _(required)_ | Label name. |
| `--color` | `string` | _(required)_ | Hex color, e.g. `#3B82F6` or `#abc`. Validated client-side. |
| `--group` | `string` | | Optional label group (e.g. `priority`, `status`). |

Requires the MANAGER role or higher; MEMBER and VIEWER get `API error (403)`.
Label names are unique per workspace: a duplicate fails with
`API error (409): A label named "Bug" already exists in this workspace`.
`--format json` prints the created label.

---

## `crewship label update`

```bash
crewship label update <label-id> --name "Critical" --color "#B91C1C"
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--name` | `string` | | New label name. |
| `--color` | `string` | | New hex color. |
| `--group` | `string` | | New label group. Pass empty string to clear. |

Only the flags you pass are sent; with none the CLI stops with
`no fields to update`. Renaming or recoloring requires the ADMIN role or higher
(MANAGER can create labels but gets `403` here). Prints
`Label updated: <name> (<id>)`; `--format json` prints the updated label. An
unknown id fails with `API error (404): Label not found`.

---

## `crewship label delete`

**Aliases:** `remove`, `rm`

```bash
crewship label delete <label-id>
crewship label delete <label-id> --yes
```

| Flag | Short | Type | Default | Description |
|------|-------|------|---------|-------------|
| `--yes` | `-y` | `bool` | `false` | Skip interactive confirmation. Required in non-TTY sessions. |

Deleting a label automatically detaches it from every issue that had
it attached.
