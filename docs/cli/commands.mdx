# Commands

`crewship commands` prints every command, subcommand, and flag the CLI supports — generated from the live command tree, so it can never drift from the binary it ships in.

This is the **agent-facing capability manifest**: read it once to learn the whole surface instead of scraping `--help` page by page.

```bash
# Human view: indented tree of names + one-liners
crewship commands
crewship commands routine run

# Machine view: full manifest
crewship commands --format json | jq '.commands[].path'
crewship commands --format json | jq '.commands[] | select(.path=="routine") .commands[].path'
```

Pass a canonical command path (separate words or one quoted argument) to
return only that subtree, retaining the global flags. Aliases are not accepted
in the path. Unknown paths print `command not found: <path>` and exit 3. The
lookup never contacts a server, so it works without login.

```bash
crewship commands routine run --format json
```

Each command includes `runnable`, optional `example`, and `inherited_flags`.
Global flags appear once in `global_flags`; `inherited_flags` contains only
options inherited from intermediate command groups.
Local flags include `required: true` when Cobra marks them individually required.
The schema also has a `deprecated` field, but marking a flag deprecated hides it,
and hidden flags are left out, so current builds never emit it. Conditional flag groups are still described by
command help; `required` is not a complete input schema. Defaults come from the
flag definitions, never the current flag values or stored credentials.

For API operations and request/response schemas, see [API](/cli/api).

## Manifest shape

```json
{
  "version": "1.2.3",
  "global_flags": [
    {"name": "format", "shorthand": "f", "type": "string", "usage": "…"},
    {"name": "no-color", "type": "bool", "default": "false", "usage": "…"}
  ],
  "commands": [
    {
      "runnable": true,
      "path": "routine run",
      "use": "run <slug>",
      "short": "…",
      "flags": [{"name": "wait", "type": "bool", "default": "false", "usage": "…"}]
    },
    {
      "runnable": true,
      "inherited_flags": [{"name": "local", "type": "bool", "default": "false", "usage": "…"}],
      "path": "db migration-status",
      "use": "…"
    }
  ]
}
```

Empty fields are omitted rather than printed empty: a flag whose default is the
empty string has no `default` key, and `shorthand`, `example`, `aliases`,
`inherited_flags`, `flags`, `commands` and `required` appear only when set. `version`, `global_flags`, `commands` at the top level and `runnable`,
`path` and `use` on each command are always present.

Hidden commands, hidden flags (including deprecated aliases) and cobra's
built-in `help` command are excluded. `completion` is included. A hidden
command whose feature is paused stays in the manifest so agents can still find
its documented pause; `hooks` is the current example.

## Output formats

| Format | Output |
| --- | --- |
| `table` (default) | Indented tree of command names and one-line descriptions, followed by a pointer to the JSON manifest. |
| `json`, `yaml`, `ndjson` | The full manifest described above. |
| `quiet` | One canonical command path per line, depth-first (for example `routine run`), with nothing else. |
