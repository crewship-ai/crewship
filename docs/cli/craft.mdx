# crewship craft

This experimental human CLI uses the separate native profile. The server flag
is off by default. Existing documents are never converted. Agent mandates,
proposals are separate surfaces. Whole-document actions operate only on an
existing explicit native Page and its qualified startup profile.

```bash
crewship craft availability <page>
crewship craft preview <page>
crewship craft versions <page>
crewship craft connect <page>
```

`preview` reads only `GET /api/v1/pages/{slug}/craft/preview` under ordinary
human authentication, without opening a native admission or acquiring a lease.
A missing shared version or redirect is an error; it never falls back to private latest bytes.

`availability` reads `GET /api/v1/pages/{slug}/craft/availability`. `connect`
creates one session with `POST /api/v1/pages/{slug}/craft/sessions`, prints only
its public `session_id`, then reads one JSON action per stdin line. The private
session token stays in process memory and is attached as `X-Craft-Session`.
Responses default to escaped NDJSON. With `-f yaml`, each response is a YAML
document separated by `---`; stdin actions remain NDJSON. Availability honors
the same output format flag. Authentication and workspace selection use the
normal CLI context.

A refusal prints the server's error text with the private session token
removed, and exits with the usual [classified code](/cli/overview):
`5` for a `409`, `2` for `400`/`422`, `7` for a `5xx`, `8` when the request
never got a response. Under `--format json` the error envelope carries the
status and the redacted body under `error.extensions`. A `409` on a lease action
(`acquire`, `renew`, `release`, `request-handoff`, `handoff`) is followed by one
`status` read so the message names the current holder, for example
`(lease held by human "Jana", generation 12)`; the lease document is added to
`error.extensions.lease`. A refusal whose body carries a `proposal` adds its
state, so a stale proposal reads `(proposal state: stale)` while an already
decided one keeps the server's "already decided" text. The native agent `task`
commands keep their status-only messages (`native HTTP 503`), because their
refusal bodies can describe a private runtime, but exit with the same codes.

### Version history

`crewship craft versions <page>` opens one native admission
(`POST /api/v1/pages/{slug}/craft/sessions`), reads
`GET /api/v1/pages/{slug}/craft/document/versions` under it and exits. It never
acquires the lease and never writes; the private session token is not printed.
Inside `connect`, the `versions` action reads the same listing on the open
connection.

The listing needs the same rights as `read`: a reader may list, a comment-only
person or a non-member gets the same refusal as `read` (`403`, exit code `4`).
While the workspace feature flag `craft_version_history` is off (the default),
the route answers `404` (exit code `3`).

```bash
crewship craft versions @PAGE_ID --format json
```

```json
{
  "currentVersion": "3",
  "truncated": false,
  "versions": [
    {"version": "3", "createdAt": "2026-10-31T10:00:00Z", "author": {"actorId": "user:USER_ID", "kind": "human", "displayName": "Pavel"}, "restoredFrom": "1", "current": true},
    {"version": "2", "createdAt": "2026-10-31T09:00:00Z", "author": {"actorId": "agent:AGENT_ID", "kind": "agent", "displayName": "Drafting Agent"}, "current": false},
    {"version": "1", "createdAt": "2026-10-31T08:00:00Z", "author": {"actorId": "user:USER_ID", "kind": "human", "displayName": "Pavel"}, "current": false}
  ]
}
```

Versions are newest first; `current` marks the head. At most 200 entries are
returned; `truncated: true` means older versions exist and remain restorable.
Entries carry no document bytes.

To restore, use the `restore` action inside `connect` while holding the lease.
It is the fenced write a save uses (current generation, `baseVersion` equal to
the latest version) and appends `baseVersion + 1` with the target's content;
nothing is deleted:

```json
{"action":"restore","snapshot":{"workspaceId":"WORKSPACE","pageId":"PAGE","applicationId":"wordcraft","enginePin":"ENGINE_PIN","sessionId":"PUBLIC_SESSION_ID","generation":"1","baseVersion":"3","targetVersion":"1"}}
```

A stale generation, a moved-on `baseVersion` or a missing lease answers `409`
(exit code `5`); without edit rights the answer is `403`.

### Agent proposals

When a person holds the lease, an agent task does not wait or steal it: its
`craft_propose` tool records a complete candidate over the exact version it read
and leaves the document unchanged. `proposals` lists them (author, base version,
summary, state); `proposal` returns the candidate bytes for comparison.
`accept-proposal` saves the candidate as this connection's own write: it needs
the current generation of this connection's lease and re-checks Page rights, the
lease and that the document is still at the proposal's base version, all in one
transaction. If the document changed meanwhile, the proposal becomes `stale` and
nothing is applied. `reject-proposal` needs write rights but no lease. Decisions
are final.

Use the actual generation returned by the server; it is a canonical positive
int64 decimal **string**. Handoff targets an opaque server-issued request ID,
never an actor supplied by the CLI. Unknown fields, including a different Page
or session, are rejected. Lease/control action lines are limited to 16 KiB. Document mutation lines use
`{"action":"save","snapshot":{...}}` (or import/restore/reconcile) with the exact
[whole-document binding](/specs/craft-native); the decoded native bytes are
bounded to 32 MiB and the encoded NDJSON line to45MiB. A document `read` response
may also use 45 MiB; other responses and SSE events remain bounded to 64 KiB. A
connection accepts at most 4096 actions. Native bytes are base64, never HTML
exports. The snapshot public session ID must match this connection; private
admission tokens never belong in the snapshot. No automatic mutation retry
occurs after a conflict or unknown ACK.

`watch` consumes the server's live SSE stream until cancellation or stream end;
it does not process later stdin actions. Only a valid `session_retired` event
is a confirmed clean end; unexpected EOF reports an unconfirmed disconnect.
The server heartbeat renews the
current holder while connected. Other actions have the normal CLI request
timeout. A failed mutation stops processing without an automatic retry or
reacquisition. EOF does not save content or release/reacquire a lease; send an
explicit `release` when wanted. Reauthorization uses the current CLI credential
and cannot revive an expired admission or replace its original authority.

## Initialize one owned Word Page

`crewship craft initialize <page> --file <native.json>` calls
`POST /api/v1/pages/{slug}/craft/initialize` with Word native bytes (at most
32 MiB). The Page must already exist, be empty, and be personally owned by the
current human with `pages:write`. The server chooses all qualified pins and
atomically creates its initial native version and lease. This does not convert
legacy content or create a Page.

The command retains the issued private admission in its process and prints only
public session, Page, application, generation and version strings. Subsequent
NDJSON actions use that admission exactly as `connect`; there is no implicit
second session or lease acquisition. EOF does not release or commit content.
Use an explicit `release` action when required. `--file -` consumes stdin as
raw native bytes and ends without subsequent NDJSON actions.


## crewship craft task

These human commands require the separate default-off native agent flag and
current Page write rights. They use normal CLI authentication and workspace
selection; they do not create an editor session or borrow an agent identity.

### crewship craft task start

```sh
crewship craft task start @PAGE --chat-id CHAT --message-id MESSAGE --whole-document --workspace WORKSPACE
```

`--chat-id` selects the registered agent chat, `--message-id` selects your own
persisted original instruction and `--whole-document` supplies explicit consent
for this one task. All three are required; consent defaults to false and
`--whole-document=false` is refused before any request. Acceptance means queued,
not executed or saved. Start never automatically retries or follows redirects.

### crewship craft task status

```sh
crewship craft task status @PAGE WORK_ID --workspace WORKSPACE
```

Status reads the actual bounded host timeline and the last confirmed receipt.
That receipt is historical; an uncertain or in-flight later attempt is not Saved.

### crewship craft task stop

```sh
crewship craft task stop @PAGE --workspace WORKSPACE
```

Stop withdraws your current agent mandate for that Page and requests process
termination. The response distinguishes revoked custody from a process whose
stop is still pending. It cannot force a human holder and does not replay a
failed mutation. Existing document content and versions remain available.


## Publish a native preview from the current connection

Use the `share` NDJSON action inside `crewship craft connect <page>` after
acquiring the current lease and confirming the saved native version. Its
`snapshot` contains only `workspaceId`, `pageId`, `applicationId`, `enginePin`,
public `sessionId`, `generation`, `baseVersion` and `targetVersion`. Versions and
generations are canonical positive decimal strings. Do not include native bytes,
`editorRevision` or `contentHash`: publishing selects an existing committed
version and cannot save a pending buffer. The server checks current edit rights,
lease generation, latest-version CAS and an atomic publication audit.

```json
{"action":"share","snapshot":{"workspaceId":"WORKSPACE","pageId":"PAGE","applicationId":"wordcraft","enginePin":"ENGINE_PIN","sessionId":"PUBLIC_SESSION_ID","generation":"1","baseVersion":"2","targetVersion":"2"}}
```

The opaque admission bearer stays in the existing connect process and its HTTP
header. It is never an argument or printed response field. Publication is sent
once; a refusal, redirect or lost response never triggers a replay. The `phase: "shared"`
receipt confirms only publication of that version, not an unsaved native buffer.
