This page covers the Docs backend. Native Craft Word and Sheet documents use
[Word and Sheet editing](/guides/artifacts/word-and-sheet).

<Note>
History browsing and compare do not need `NEXT_PUBLIC_DOCUMENT_REVIEW_ACTIONS`.
Keep that development-only flag off: the server does not serve the review
endpoints its client controls call.
</Note>

## Compare

Open **History**, pick a revision, then **Compare with saved version**. Each changed
block is labelled **Added**, **Removed**, **Changed** or **Moved** with its
before and after text. The comparison is against the last saved version; unsent
edits are not included, and the page says so. Comparing never edits the document.

Compare also reports formatting and attribute changes (a link target or a
heading level). Blocks are matched by stable ID, or by identical content when
a block has none.

## Revert a change

The per-change review action is not a supported workflow in this release.
To recover saved content, inspect the retained checkpoint first. The existing
`crewship doc restore` command restores a checkpoint as a new revision with
revision and epoch checks; preserve its original request packet if the outcome
is unknown. See [Docs CLI](/cli/doc).
