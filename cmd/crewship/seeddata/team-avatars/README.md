# Demo colleague portraits

Generated deterministically with the existing `@dicebear/avataaars` package and
`scripts/generate-team-avatars.mjs`. These are fictional illustrated portraits,
not photographs of real people. No external image service is needed at runtime.
Avataaars artwork: Pablo Stanley, https://avataaars.com/ — package metadata states
“Free for personal and commercial use”. The repository's pinned DiceBear versions
are used; no new dependency is introduced.
