# Mirror: Template Crewship Slides

- **Original:** https://claude.ai/artifact/CBBoNZhbaHvUUUz2aQ2Ccv (claude.ai Slides
  type, version `1794126859-4958`, read 2026-11-08). Four slides: `cover`,
  `features`, `chart`, `flow`.
- **Crewship kind:** Slides artifact project. Seeded as Page `ref-slides-template`
  ("Template Crewship Slides") through `POST /api/v1/pages/artifacts`
  (`crewship page artifact create`), registered in `seeddata/mirror_cbbo.go`.
  The server reads it with `artifacts.ParseSlidesArtifact` and the Artifacts
  library shows it in the Slides kind view.

## Files

| File | What |
| --- | --- |
| `deck.json` | Crewship deck index `{schema_version: 1, order}`; same slide ids and order as the original. |
| `slides/<id>.html` | One `<section>` per slide in the Crewship closed profile, readable source. |
| `m-deck.json` | The manifest the seed posts: `deck.json` and the four slides verbatim. A test fails when it drifts from the files above. |

The slides were generated by a small script from the original's flex layout,
resolved to absolute pixels on the same 1920×1080 canvas with the same
margins (128 px, 160 px at the bottom where the original has a footer).

## What is 1:1

- Slide ids, order, every visible text and every speaker note, verbatim
  (Czech, including `·` and `–`).
- Colours: every background, text, card, border and bar colour is the
  original hex.
- Layout: heading positions, the three-card row, the bar chart (bar
  geometry taken from the original SVG, labels centred under each bar), the
  four-box process row with connectors, and footers at `bottom: 64px`.
- Font sizes, except where the profile's limit applies (below).

## Known gaps (Crewship Slides profile, not faked)

The Crewship artifact Slides profile admits only text (`p`), rectangle and
ellipse shapes (`div[data-shape]`) and tables, with absolute pixel geometry,
hex colours and the single font Go Regular. So:

1. **Typefaces:** IBM Plex Sans and JetBrains Mono (deck `faces`) render as
   Go Regular. No font weights: headings and the bold `T6 · 38` label lose
   their weight.
2. **Line height and letter spacing:** the renderer uses line height 1.2;
   the original's 1.05 (cover title) and 1.3–1.4 (body text) and the eyebrows'
   `letter-spacing: 4px` are not carried.
3. **`text-transform: uppercase`:** the two eyebrows ("Template · Slides",
   "Co umí Slides") are stored as shown, in capitals.
4. **Gradient:** the cover panel's `linear-gradient(160deg, #16304F 0%,
   #0F1F33 70%)` is a solid `#16304F` rectangle.
5. **Icons (`x-icon`):** no icon primitive. The cover's large "Users" icon is
   drawn from its own geometry (heads and shoulders as outlined ellipses,
   panel-coloured masks where the icon's arcs end; stroke 16 px, the
   profile's maximum, instead of 23 px). The card icons Chat, Play and
   PaperPlane cannot be drawn from rectangles and ellipses; their 72 px slots
   stay empty so the card text sits where it does in the original.
6. **Rounded corners:** cards, process boxes and chart bars are square
   (no `border-radius` in the profile).
7. **Big number:** "38" is 160 px, the profile's maximum font size, instead
   of 200 px.
8. **Chart:** the inline SVG becomes six native rectangles; its
   `aria-label` ("Sloupcový graf: dokončené úkoly T1 až T6 – 12, 18, 15, 24,
   31, 38") has no carrier, and the same values are visible in the labels.
9. **Connectors:** each `x-connector` is a 96×4 px line; no arrowhead.
10. **Transitions and builds:** `data-transition` (fade, push) and the
    icon's `data-build-in="pop"` are not supported; Present shows slides
    without animation.
11. **Deck metadata:** the original index's `title` becomes the Page name;
    its outline (`sections`: "Úvod: co je Crewship", "Ukázka funkcí Slides:
    karty, graf, diagram") has no field in the Crewship deck index.
