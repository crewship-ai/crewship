# Mirror: Template Crewship Slides

- **Original:** https://claude.ai/artifact/CBBoNZhbaHvUUUz2aQ2Ccv (claude.ai Slides
  type, version `1794126859-4958`, read 2026-11-08). Four slides: `cover`,
  `features`, `chart`, `flow`.
- **Crewship kind:** Slides artifact project. Seeded as Page `ref-slides-template`
  ("Template Crewship Slides") through `POST /api/v1/pages/artifacts`
  (`crewship page artifact create`), registered in `seeddata/mirror_cbbo.go`.
  The server reads it with `artifacts.ParseSlidesArtifact` and the Artifacts
  library shows it in the Slides kind view.

## Files

| File | What |
| --- | --- |
| `deck.json` | Crewship deck index `{schema_version: 1, order}`; same slide ids and order as the original. |
| `slides/<id>.html` | One `<section>` per slide in the Crewship closed profile, readable source. |
| `m-deck.json` | The manifest the seed posts: `deck.json` and the four slides verbatim. A test fails when it drifts from the files above. |

The slides were generated by a small script (`gen_cbbo.py`, kept with the
build notes outside the repository) from the original's flex layout as Chromium
lays it out with the original fonts, written as absolute whole pixels on the
same 1920×1080 canvas. They use the Slides **rich profile** (schema 3 in the
projection; see `docs/guides/artifacts/slides.mdx`).

## What is 1:1

- Slide ids, order, every visible text and every speaker note, verbatim
  (Czech, including `·` and `–`).
- Colours: every background, text, card, border and bar colour is the
  original hex, and the cover panel's `linear-gradient(160deg, #16304F 0%,
  #0F1F33 70%)`.
- Typography: IBM Plex Sans and JetBrains Mono (the deck `faces`), weights
  700 (headings, "38", "T6 · 38") and 600 (card and box titles), the
  eyebrows' `letter-spacing: 4px`, every `line-height` the original sets
  (1.05, 1.1, 1.4, 1) and the faces' `normal` line height (1.3 Plex, 1.32
  Mono) where it sets none, and every font size including the 200 px "38".
- Layout: element boxes measured from the original; rounded corners on cards
  (24 px), process boxes (24 px) and chart bars (6 px, from the SVG's `rx`).
- Connectors: each `x-connector` is a 4 px line with a triangle arrowhead.
- Icons: the cover's large icon and the three card icons, in the original
  colour, size and position.
- Transitions: `fade` on cover, chart and flow and `push` on features, played
  by Present.

Rendered at 1920 and 390 px wide next to the original HTML (same fonts), the
mean per-pixel difference is at most 4.2 of 255 levels on every slide (0.6–2.3
at 1920 px); what differs is listed below.

## Remaining gaps (not faked)

1. **`text-transform: uppercase`:** the profile has no text transform; the two
   eyebrows ("Template · Slides", "Co umí Slides") are stored as shown, in
   capitals.
2. **Icon glyphs:** the original names claude.ai's own icons (`Users`, `Chat`,
   `Play`, `PaperPlane`). Crewship draws icons only from its bundled Lucide
   set, so these are `users`, `message-circle`, `play` and `send`; the
   outlines can differ in detail from claude.ai's glyphs.
3. **Build-in animation:** the cover icon's `data-build-in="pop"` has no
   carrier; the profile animates whole slides only.
4. **Connector look:** the claude.ai runtime's `x-connector` arrowhead size is
   not part of the source; Crewship draws its fixed triangle (length 16 px,
   width 16 px at a 4 px stroke).
5. **Sub-pixel positions:** the original's flex layout places some text at
   fractional pixels; the profile uses whole pixels, so a few lines sit up to
   1 px off.
6. **Chart semantics:** the inline SVG becomes six native rounded rectangles;
   its `aria-label` ("Sloupcový graf: dokončené úkoly T1 až T6 – 12, 18, 15,
   24, 31, 38") has no carrier, and the same values are visible in the labels.
7. **Deck metadata:** the original index's `title` becomes the Page name; its
   outline (`sections`: "Úvod: co je Crewship", "Ukázka funkcí Slides: karty,
   graf, diagram") has no field in the Crewship deck index.
8. **Kerning:** Crewship sets the bundled faces without kerning or ligatures,
   in the deck view and the PDF alike, so both break lines the same way; the
   original kerns, so some lines are a few pixels wider here.
9. **PDF export only:** the PDF has no transitions and draws the gradient as
   128 bands of exact colours.
