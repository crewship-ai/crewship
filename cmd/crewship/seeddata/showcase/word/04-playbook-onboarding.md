# Playbook: první týden nového obchodníka

Tento playbook provede nového kolegu prvním týdnem. Každý krok má vlastníka a agent hlídá, aby nic nevypadlo.

## Den 1: přístupy a orientace

- Přihlášení do Crewship a nastavení profilu.
- Prohlídka knihovny artefaktů: nabídky, ceníky, dashboard obchodu.
- Seznámení s posádkou Obchod a jejími agenty.

## Den 2–3: první nabídka

1. Otevřete šablonu **Obchodní nabídka** a převezměte úpravy.
2. Požádejte agenta o doplnění kalkulace z ceníku.
3. Zkontrolujte čísla v sešitu **Cenová nabídka** a pošlete ke schválení.

## Den 4–5: pipeline a reporting

| Aktivita | Nástroj | Výstup |
|---|---|---|
| Kontrola pipeline | Dashboard obchodu | seznam příležitostí |
| Týdenní report | Word šablona | report pro vedení |
| Plán na další týden | Sheet | prioritizované úkoly |

## Pravidla spolupráce s agenty

- Agent navrhuje, **člověk rozhoduje**.
- Když dokument upravujete vy, agent čeká. Zámek úprav uvidíte v horní liště.
- Každou verzi lze obnovit z historie.
