# IBM Plex Sans

Unmodified WOFF2 files from the IBM Plex Sans release `@ibm/plex-sans@1.1.0`
(`ibm-plex-sans.zip`, `fonts/complete/woff2/`). Source:
https://github.com/IBM/plex/releases/tag/%40ibm%2Fplex-sans%401.1.0.

The artifact Slides renderer uses these faces (weights 400, 600, 700); the PDF
renderer embeds the TTF files of the same release from
`internal/artifacts/slidespdf/fonts/`. The SIL Open Font License and copyright
notice are in `OFL.txt` (the release's `LICENSE.txt`). Keep that file when
redistributing the font.
