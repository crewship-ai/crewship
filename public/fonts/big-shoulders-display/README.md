# Big Shoulders Display

Weights 800 and 900, `latin` and `latin-ext` woff2 subsets from the Fontsource package
`@fontsource/big-shoulders-display` (the Big Shoulders Display family, Patric King / Chicago
Digital Services, via Google Fonts), unmodified. Used only for page titles and big numbers by the
Afterglow theme pack (`lib/theme-packs/afterglow.ts`); the browser fetches the files only while that
pack is in use. The SIL Open Font License is in `OFL.txt`; keep it when redistributing.
