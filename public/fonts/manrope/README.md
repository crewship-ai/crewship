# Manrope

Variable font (weights 200-800) from the Fontsource package `@fontsource-variable/manrope` 5.x,
unmodified `latin` and `latin-ext` woff2 subsets of Manrope by The Manrope Project Authors
(https://github.com/sharanda/manrope). Used only by the Afterglow theme pack
(`lib/theme-packs/afterglow.ts`); the browser fetches the files only while that pack is in use.
The SIL Open Font License is in `OFL.txt`; keep it when redistributing.
