# Inter

Unmodified `InterVariable.woff2` from the official Inter 4.1 release
(`Inter-4.1.zip`, sha256 `9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`).
Source: https://github.com/rsms/inter/releases/tag/v4.1.

One variable file covers every weight the interface uses (400–650), so the UI
needs no external font service. The SIL Open Font License and copyright notice
are in `OFL.txt` (the release's `LICENSE.txt`). Keep that file when
redistributing the font.
