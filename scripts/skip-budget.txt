# Skip budget baseline — the maximum number of `t.Skip` / `t.Skipf` /
# `t.SkipNow` calls allowed in tracked *_test.go files.
#
# Enforced by scripts/skip-budget.sh, which runs in the `shell` job of
# .github/workflows/ci.yml. The gate fails when the count RISES above this

# the win here.
#
# To raise this number legitimately, see the failure message the script
# prints: tracking issue + `// SKIP-WAIVER(#NNNN):` comment above the skip +
# the bump in the same commit.
