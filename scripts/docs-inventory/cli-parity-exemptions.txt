# CLI parity exemptions — read by `go run ./scripts/docs-inventory` (cliparity.go).
#
# One exemption per line: an optional HTTP method, a public API path, then
# whitespace and the reason it has no `crewship` command. A line with a method
# (`PUT /api/v1/crews/{crewId}  reason`) exempts that one operation; a line
# with only a path exempts every method on it. A line with no reason is a
# parse error, and so is a method that is not an upper-case HTTP method.
# Paths are matched by shape ({crewId} and {id} are the same segment), so
# spell them as the OpenAPI document does. The tool prints a notice for every
# line here whose operations have since gained a CLI caller or left the spec;
# delete those lines.
#
# Three kinds of line live here, and only the first kind is meant to stay.
