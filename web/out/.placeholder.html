The Crewship web UI was not built into this binary.

This is a placeholder page, not the application. The Go binary embeds the Next.js static export from web/out/, and that export was never produced for this build — so there is no UI to serve. The HTTP API and the crewship CLI are unaffected.

Fix it

From the repository root:

make build        # pnpm build → scripts/embed-web-out.sh sync → go build

or, if you only want the frontend refreshed into the embed directory:

pnpm build
./scripts/embed-web-out.sh sync

Then rebuild the binary. ./dev.sh start does all of this for you and is the normal way to run Crewship locally.

If you are seeing this from a released build

That is a packaging bug — a release is supposed to fail before it ships a binary without the UI. Please report it at github.com/crewship-ai/crewship/issues and include the output of crewship version.
