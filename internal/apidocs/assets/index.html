How to read this

  • Paths, methods and path parameters are exact. They are generated from the route registrations, so they match this build of this instance. A method not listed for a path is refused with 405.
  • required is asymmetric. A parameter marked required was seen to make the handler answer 4xx when absent — treat it as binding. A parameter not marked required means not proven required, not proven optional.
  • Bodies are derived, not authored. Where the generator could not derive a shape from the handler it emits an unconstrained object, and this page says so on the field rather than presenting an empty object as a contract.
  • Unauthenticated operations are marked public. Everything else needs one of the credentials named on its page.
